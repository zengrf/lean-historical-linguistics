# M4 bounded reconstruction fixtures

All examples are synthetic, under the repository's MIT license. They do not
assert a historical reconstruction. The [manifest](manifest.json) fixes the
expected completion state, exact ordered candidate list, reason/error code and
rationale for every fixture. Expectations are authored independently of Lean
execution and reproduced by `scripts/build_m4_fixtures.py`.

There are 82 fixtures: **25 complete, six incomplete and 51 invalid**. Completed
cases include a unique candidate, mergers with multiple ancestors, distinct
analyses of the same word, linked reading tuples, ambiguous branch models,
deletion, Unicode atoms, empty words, missing data, one-segment unknown readings,
morpheme bounds, chronology and an M3 evidence bridge. Incomplete cases exercise
zero/partial budgets, empty/nonempty prefixes, a zero deadline and a space ceiling.
Invalid cases target model/observation bounds, joint bindings, package identities,
M2 grammar validation, M3 mismatches and strict byte/JSON handling.

Every query declares an explicit proto inventory, length bound, finite list of
whole joint analyses, analysis/rule limits, doculect axis and execution budget.
Null forms represent absence; `[]` represents an observed empty word. An unknown
reading occupies exactly one segment. Gaps are not original observations.
Candidate records retain analysis IDs, proto nodes, choice bindings and complete
per-branch M2 derivation certificates.

The source M3 fixture in `complete/m3-bridge.json` is copied from
[`data/correspondence/sites/shared-01.json`](../correspondence/sites/shared-01.json).
Its complete correspondence dossier is checked, and each selected original and
source reference must match exactly. The source remains synthetic.

The larger exhaustive comparison is generated by `scripts/verify_m4.py`: 121
protoforms and 121 possible observed words of length at most four over `{a,b,c}`,
for each of 16 cascades. It checks 1,936 complete inverse sets and 234,256
membership decisions. These queries are not counted as additional authored
fixtures. Exact inverse sets are recorded in
[`exhaustive-small-domain.json`](../../reports/exhaustive-small-domain.json).

See the [versioned semantics](../../docs/bounded-reconstruction-semantics.md) and
[delivery guide](../../docs/10-m4-delivery.md) for the command-line interface,
proof boundaries and timeout protocol. A complete empty result only rules out
candidates in the declared finite space. An incomplete result never makes even
that bounded negative claim.
